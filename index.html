Sincronização Google Forms → Sistema

Configure o Google Apps Script na planilha de cadastro para enviar novos clientes automaticamente ao sistema.

Cole este código no Google Apps Script da planilha:
function onFormSubmit(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var row = e.range.getRow();
  
  var nome = sheet.getRange(row, 2).getValue();   // Coluna B
  var doc  = sheet.getRange(row, 3).getValue();   // Coluna C
  var end  = sheet.getRange(row, 6).getValue();   // Coluna F
  var email= sheet.getRange(row, 10).getValue();  // Coluna J
  var tel  = sheet.getRange(row, 11).getValue();  // Coluna K

  var payload = JSON.stringify({
    nome: nome, doc: String(doc), endereco: end,
    email: email, tel: String(tel),
    status_cadastro: "pendente", de_confianca: false
  });

  var options = {
    method: "POST",
    contentType: "application/json",
    headers: {
      "apikey": "SUPABASE_KEY_AQUI",
      "Authorization": "Bearer SUPABASE_KEY_AQUI",
      "Prefer": "return=representation"
    },
    payload: payload
  };

  UrlFetchApp.fetch(
    "https://bqqkplmfoumvjmwqwwgs.supabase.co/rest/v1/clientes",
    options
  );
}
Como configurar:
1. Abra a planilha de cadastro → Extensões → Apps Script
2. Cole o código acima
3. Substitua SUPABASE_KEY_AQUI pela chave do Supabase
4. Salve e configure o gatilho: Gatilhos → + Adicionar → onFormSubmit → Ao enviar formulário
5. Pronto! Novos cadastros entram automaticamente com status "Pendente"
